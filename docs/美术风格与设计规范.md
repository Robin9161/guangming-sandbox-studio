# 光明沙盘 Studio · 美术风格与设计规范

> **给接手的人和 AI**：动任何画面相关的代码之前，先读完这份文档。
> 这里记录的是已经和项目负责人反复调过、确认过的风格。新做的东西要沿用它；想改其中的规则，先和负责人确认，再同步改这份文档（文末有变更记录）。
> 文档里的数字都对应代码里的实际取值，标了出处。**代码和文档对不上时，以代码为准，并把文档改正。**

---

## 1. 风格定位

**一句话：浅色微缩沙盘，让天光来上色。**

- **白天**：奶油白的建筑体块、浅土色地面、马卡龙绿的山和树、灰蓝的路网，像一个精致的实体沙盘模型。物体本身颜色很浅、很素，画面的情绪全靠一天中变化的光色。
- **黄昏和清晨**：天空和远处的雾可以很浓烈（粉、橙、紫），地面和建筑只带一点同色调的倾向。
- **夜晚**：城市是深蓝的渐变剪影，只有少数高楼成排亮起暖黄的窗，冷暖对比分明；少数真实的地标有一种颜色的夜光（如虹桥的红）。
- **整体**：有微缩模型摄影的质感（接缝处的柔和暗部、画面上下轻微虚化、暗角），远景层层溶进地平线色的雾里。

风格来源：

1. 《无尽动画》项目（借鉴 ALTO 系列游戏的配色方法）：一天的配色由少数关键色派生，雾色 = 地平线色，关键帧之间在 OKLCH 色彩空间插值。
2. 水粉画的城市夜景：楼体是从下往上变暗的剪影，远处的灯是暖色的，与冷色的楼体形成反差。
3. 微缩模型摄影：移轴虚化、柔和的环境光遮蔽。

用途：**做视频里的三维动画镜头**（4K60 成片，航拍、全景为主，偶尔推近）。所有风格决定都优先考虑"作为视频画面好不好看"。

## 2. 核心原则

每条原则都写了原因。新做的效果先对照这几条。

### P1 整帧颜色只由少数关键色派生

一帧画面里的所有颜色只来自这几个随时间变化的关键色：

| 关键色 | 用在哪里 |
|---|---|
| 天顶 `top`、天中 `mid`、地平线 `horizon` | 天空三段渐变 |
| 雾色 `fog`（默认 = 地平线色） | 距离雾、体积雾、远山 |
| 阳光 `sun` + 强度 `sunI` | 太阳（夜里是月光） |
| 天光 `sky`、地光 `ground` + 强度 `hemiI` | 半球光 |
| 暗部色 `shadow`、亮部色 `high` + 强度 `grade`、饱和度 `sat` | 全局调色 |
| 空气感 `haze`、夜间系数 `night` | 雾的浓度；夜景、星星、泛光 |

**原因**：颜色从同一组关键色派生，任何时刻画面都是协调的；改一处，整帧一起变。
**规则**：新做的东西不要自己写死一个"好看的颜色"，要从这些关键色取（读 `look/uniforms.ts` 里的 uniform 或 `driver.look.colors`）。
出处：`src/style/artPalette.ts`

### P2 雾色 = 地平线色，远处的东西没有自己的颜色

远景按距离溶进地平线色。远处的山、楼、水面不需要也不应该有独立配色。

**原因**：这是 ALTO 风格的空间感来源，层次靠"多远就多像天边"来表现。
出处：`look/driver.ts` 中的距离雾和体积雾颜色。

### P3 克制：浓烈的颜色只给天空和远处的雾

照到地面和建筑上的光，只带一点天空颜色的倾向。

```
RESTRAINT = { lightChroma: 0.55, moodOnLight: 0.25, grade: 0.55 }
```

- `lightChroma`：阳光、天光、地光、调色色只保留 55% 的彩度
- `moodOnLight`：日出日落的"氛围"作用到光照上只有 25%（天空是全量）
- `grade`：全局调色强度再乘 0.55

**原因**：负责人的原话是"核心是地面还有建筑颜色太过浓烈，天空还好"。玫瑰、紫暮这类氛围之前把整个城市染成粉紫色，很难看。
**规则**：不要为了"更有氛围"而调高这三个数。想要更浓烈的感觉，改天空关键色。
出处：`src/style/artPalette.ts`

### P4 颜色插值在 OKLCH 里做，冷暖之间绕品红走

关键帧之间在 OKLCH 里插值；从冷色到暖色时，色相绕品红一侧走（青 → 蓝紫 → 粉 → 橙）。

**原因**：直接按 RGB 插值，日落时会经过一段发灰发脏的颜色。绕品红走，过渡是干净的粉紫。
**规则**：新增随时间变化的颜色，用 `artPalette.ts` 里的插值函数，不要自己线性混合 RGB。

### P5 物体本色浅、低饱和，让光来上色

| 物体 | 颜色 | 出处 |
|---|---|---|
| 建筑 | `#f8f6f1` `#f3f1ec` `#f6f5f2` 等奶油白；屋顶略亮 | `style/palette.ts` buildingColors |
| 城区地面 | `#efe5cf` | ground.urban |
| 山体绿（按海拔 55 / 100 / 160 / 230 m 分阶） | `#a9cf86` `#93c274` `#7fb365` `#6c9f58` | ground.hills |
| 区界外 | 逐渐褪到底板色 `#ebe6da`（最多 80%） | world/terrain.ts |
| 树冠 | `#7fbf5f` `#94cc6a` `#6aad55` `#a6d477` | trees.crowns |
| 道路（按等级由深到浅） | `#6f7787` … `#a9afb9` | roadStyle |
| 大道中央绿带 | `#8fc46f` | avenueMedian |
| 水 | 基础色 `#7fd3e0`，实际颜色随天光变化（见第 7 节） | water |

**原因**：物体颜色越浅越素，天光的颜色越能体现出来；饱和的物体色会和天光打架。
**规则**：新增物体（地标、交通、人流等）也用浅色、低饱和；需要强调的东西靠光（夜光、轮廓光）而不是靠高饱和的固有色。

### P6 夜景：渐变剪影 + 少量暖窗 + 冷暖反差

- 楼体在夜里是**竖向渐变的剪影**：楼脚偏亮的蓝（`0.02, 0.035, 0.12`）→ 楼顶近黑的藏青（`0.004, 0.006, 0.022`）。不同朝向的墙深浅略有不同，体块不会糊成一片。
- 楼体换成剪影要比天色变暗得**更快**（夜间系数 0.1 → 0.55 之间完成），蓝调时刻就已经是剪影。否则残留的白天浅色会让墙发灰，"像蒙了一层雾"。
- **只有高楼亮灯**：楼高 32 m 以下基本不亮，70 m 以上亮得最多；同一层的窗大多一起亮（"成排亮"）。
- 窗灯是单一的柔和暖黄白（`1.0, 0.8, 0.48`）。远处窗格小于一个像素时，只留很淡的平均光，避免整面墙均匀发光像灯箱。
- 推近时，没亮的窗是很暗的蓝玻璃，立面有质感，不是一块死黑。
- 亮灯比例随时间变化：18:18 开始亮，20:00 到最多；22:00 以后逐渐熄掉一部分；凌晨 4:30–6:00 全部熄灭。
- 夜里移轴减弱（`tilt = 1 − 0.85·night`），不让小光点被糊掉；泛光增强（`bloom = 0.15 + 0.5·night`）。

**原因**：负责人反馈过"晚上的建筑发光很难看""亮成了一片"。参考了水粉画后确认，城市夜景的美感来自冷色剪影和少量暖光的反差，而不是灯多。
**规则**：不要给所有楼都加灯，不要提高亮灯比例让城市"更热闹"，不要用白色或多种颜色的窗光。
出处：`src/world/city.ts`、`look/driver.ts`（`U.lit`）

### P7 彩色光：少、真实、单色

- 只给**少数**有现实依据的地标加彩色夜光，每个地标**只用一种颜色**。
- 现有：**虹桥**（虹桥公园的红色步道桥，现实中夜里是红光）发光色 `#ff3a2c`，强度 `smoothstep(night, 0.15, 0.6) × 1.6`。
- 新增彩色光之前，先查证这个地标现实中夜里是什么颜色的灯；查不到就不加。

**原因**：彩色光是点缀，多了就俗，而且会破坏 P6 的冷暖反差。
出处：`src/world/bridge.ts`

### P8 天气是叠加到当天配色上的，而且慢起慢落

- 天气不自带一套配色，而是把当前时刻的配色往"同亮度的灰蓝"上拉：多云轻，雨重，雷暴最暗。雪变亮变冷，雾变灰、阳光很弱。
- 强度 0–1 慢慢起、慢慢收（约 30 秒）；手动切换时快速收掉旧的（约 1.5 秒）再起新的。
- 地面湿度和积雪比天气本身更慢：下雨约 8 秒变湿，停雨约 60 秒变干；下雪约 45 秒积满，停雪约 2 分钟化完。

**原因**：天气是"同一天的不同情绪"，画面始终和时刻协调；突变不像真实天气，也不适合做视频镜头。
出处：`src/weather/weather.ts`（`applyWeatherToLook`、状态机）

### P9 雨要克制，闪电只在夜里

- 雨丝细、淡、稀：7000 根，宽 0.0005、长 0.03（相对于雨区大小），不透明度 0.28；雨的出现比例是强度 × 0.55（雷暴 × 0.7）。
- 闪电只在**夜里**（夜间系数 > 0.5）的雷暴中出现，随机间隔 3–11 秒，每次闪两下。
- 雪花 9000 片，慢慢飘落、左右摆动。
- 雨雪的颜色跟随天光：白天浅、夜里暗（`light = 0.2 + 0.8·(1 − 0.85·night)`）。

**原因**：负责人反馈"雨太大了，少了美感，闪电可以在晚上"。
**规则**：不要加大雨丝的数量、粗细和不透明度来"增强效果"。想表现大雨，用水面涟漪、地面变湿反光、天色变暗、体积雾变浓来表现。
出处：`src/fx/precipitation.ts`、`look/driver.ts`

### P10 雾是亮的、通透的

- 体积雾的颜色取雾色和地平线色的中间，再往同亮度的灰靠 15%，再提亮 1.2 倍。**雾是亮的、通透的，不是土黄的沙尘。**
- 晴天正午几乎没有体积雾；**清晨（4:36–10:00）**和**日出日落**才浓起来；被逆光照透的雾最好看（太阳照雾强度在清晨、黄昏最强）。
- 近处的城市保持清楚：距离雾的起点跟着镜头距离走，夜里再往后推。

**原因**：负责人反馈过"建筑有很重的雾感"，雾不能把主体城市糊掉。
出处：`look/driver.ts`、`src/fx/fog.ts`

### P11 水：同一色相，用明度、清澈度、倒影区分深浅

详见第 7 节。核心规则：

- 塘、湖、水库、河是**同一个色相**，区别在于明度（深浅）、浑浊度和倒影强度。
- 岸边有一圈浅色带，离岸越远越深。
- 水面低于岸边，地形在水面范围内挖低：**岸边是缓坡，不能出现竖直的墙**。

**原因**：负责人反馈过"水坑、湖、水库颜色都一样，没有深浅变化"和"水坑周围出现了垂直的面，很假"。

### P12 微缩质感

- 环境光遮蔽（AO）给出楼与楼、楼与地面接缝处的柔和暗部，微缩模型的质感主要靠它。白天强度 0.85，夜里关闭。
- 移轴：画面上下边缘轻微虚化。
- 暗角：白天 0.3，夜里加到 0.55。
- 高程夸张：低处城区约 1.6 倍，60 m 以上逐渐加到约 2.4 倍（3.2 倍时山体过陡）。**建筑不夸张。**
- 道路按等级加宽（真实宽度的约 1.3–1.5 倍），远看时路网骨架才清楚。

一天由 10 个关键帧组成，关键帧之间按 smoothstep 缓动、在 OKLCH 里插值。完整数值见 `src/style/artPalette.ts` 的 `KEYS`。

| 时刻 | 名称 | 性格 | 天顶 / 天中 / 地平线 | 阳光强度 | 夜间系数 |
|---|---|---|---|---|---|
| 0:00 | 深夜 | 深藏青，月光偏冷蓝 | `#070d26` `#121c44` `#25325f` | 0.38 | 1 |
| 4:36 | 黎明前 | 蓝紫，地平线透出灰紫 | `#141f4e` `#3a427a` `#7a6c9c` | 0.5 | 0.8 |

| 12:00 | 正午 | 最亮、最干净，调色最弱 | `#6cb0e6` `#a6d3f0` `#e0eff4` | 3.1 | 0 |
| 15:48 | 下午 | 开始变暖 | `#68a4da` `#b2d0e6` `#f0e0c4` | 2.85 | 0 |

| 21:00 | 夜 | 回到深藏青 | `#0a1230` `#18244e` `#2e3a68` | 0.4 | 1 |

- 太阳轨迹：东升（+x）→ 南（+z）→ 西落（−x），日出 6:00、日落 18:36，最高约 62°（为了阴影好看，不按真实太阳高度）。
- 夜里月光从西南高处来，方向固定；日出日落前后在两者之间平滑转过去，阴影不跳。
- 日出日落的光晕强度：日出以 6:00 为中心、日落以 18:18 为中心的高斯曲线。

### 日出日落的"氛围"

日出日落前后，在天空上叠一层随机的氛围色（只在 `glow` 起作用时生效，天空全量，光照只有 25%）：

| 氛围 | 性格 |
|---|---|
| 素 | 不叠加 |
| 玫瑰 | 粉紫、柔 |
| 余烬 | 深红橙、浓 |
| 紫暮 | 蓝紫 + 珊瑚粉 |
| 金 | 金黄、明亮 |

默认"每天随机"：每到正午和午夜换一种（不会随机到"素"）。

## 4. 天气

| 天气 | 目标强度 | 配色变化 | 其他表现 |
|---|---|---|---|
| 晴 | 0 | 无 | — |
| 多云 | 0.8 | 往灰蓝轻拉（×0.55），阳光弱 55% | 云量增加 |
| 雨 | 0.8 | 往灰蓝拉（×0.85），变暗到 72%，阳光弱 85% | 雨丝、水面涟漪、地面变湿反光、体积雾变浓、云变灰 |
| 雷暴 | 0.97 | 最暗（55%），阳光弱 92% | 同雨，雨更密（×0.7）、水面波动更大；**夜里**有闪电 |
| 雾 | 0.85 | 变灰（×0.75），阳光弱 65%，饱和度降 | 体积雾拉满（2.2 × 强度），雾层加高到 200 m |
| 雪 | 0.85 | 变亮变冷（×0.7，亮度 108%），阳光弱 55% | 雪花、朝上的面慢慢积雪（路面积雪少一半），云量一半 |

- 自动模式：每隔一两分钟随机换一种天气，中间穿插晴天。出现权重：多云 0.35、雨 0.25、雾 0.16、雷暴 0.12、雪 0.12。
- 手动切换后 4 分钟内不会自动换。
- 天气越重，日出日落的光晕和太阳光晕越弱（天被云遮住）。
- 闪电瞬间把天空和天光照成冷白紫色（`#dcd8ff`），泛光同时增强。

新增一种天气要改的地方：`weather/weather.ts`（类型、名称、目标强度、权重、`applyWeatherToLook`）→ `look/driver.ts`（雾、雨雪、水、云的反应）→ `index.html`（面板按钮）→ 本节表格。

## 5. 雾与大气

| 项目 | 规则 | 出处 |
|---|---|---|
| 距离雾 | 颜色 = 雾色；起点 ≈ 镜头距离 ×(1 + 0.8·night) / haze，夜里再加 1500 m；终点 ≈ 起点 × 4.2 + 8000 m | driver.ts |
| 体积雾（日常"薄雾"档） | 浓度 0.12 + 0.8 × 清晨 + 0.35 × 日出日落光晕；雨雪天 ×(1 + 1.2 × 强度) | driver.ts |
| 体积雾（"浓雾"档） | 1.6，雾层高 200 m | driver.ts |
| 雾的形态 | 两层三维噪声（1400 m 和 520 m 尺度），随风缓慢飘动；按高度指数衰减（日常 120 m）；雾体边缘 500 m 内渐隐 | fx/fog.ts |
| 太阳照雾 | 0.8 + 1.0 × 光晕 + 0.6 × 清晨；夜里没有 | driver.ts |
| 星星 | 只在夜里、只在地平线以上；天气越重越少 | world/sky.ts |
| 云 | 低多边形的云团，慢慢飘，投下移动的云影；颜色往地平线色靠 35%，夜里变成暗蓝灰；阴雨天变灰、逐朵长出更多的云 | world/clouds.ts |

## 6. 夜景参数速查

| 项目 | 取值 |
|---|---|
| 剪影切换 | `smoothstep(0.1, 0.55, night)` |
| 剪影颜色 | 楼脚 `(0.02, 0.035, 0.12)` → 楼顶 `(0.004, 0.006, 0.022)` |
| 亮灯楼高 | `smoothstep(32 m, 70 m, 楼高)` |
| 窗格 | 开间 3.6 m × 层高 3.4 m；窗占格子的 60%（横）× 56%（竖） |
| 窗灯颜色 | `(1.0, 0.8, 0.48) × 2.4`，乘夜间系数 |
| 亮灯比例 `lit` | 18:18–20:00 升到 0.3；22:00 起降到 0.13；4:30–6:00 熄灭 |
| 每栋差异 | 约 30% 的楼几乎不亮（×0.15），其余 ×0.7–1.5 |
| 地标夜光 | 虹桥 `#ff3a2c` × 1.6 |
| 泛光 | 0.15 + 0.5 × night（闪电时 + 0.6） |

## 7. 水面

| 等级 | 判定 | 深度上限 | 倒影强度 | 岸边浅色带 | 性格 |
|---|---|---|---|---|---|
| 塘 pond | 数据标为 pond，或面积 < 1 万 m² | 0.3 | 0.35 | 1.0 | 最浅、略浑、倒影弱 |
| 湖 lake | 其余 | 0.7 | 0.75 | 0.6 | 标准水色 |
| 水库 reservoir | 数据标为 reservoir，或面积 > 20 万 m² | 1.0 | 1.0 | 0.35 | 最深、最冷，倒影像镜面 |
| 河 river | 河道面 / 线状的河溪渠 | 0.5 / 0.45 | 0.4 / 0.35 | 0.5 / 0 | 流动的水，倒影弱，只反射天色 |

- 深度 = 近岸浅色带（约 16 m 范围，占三成）+ 离岸越远越深（约 125 m 范围，占七成）× 这一级的深度上限。
- 颜色：基础水色白天往地平线色靠 30%，夜里变成深蓝 `#2a5878`。浅水往泥土的青绿 `#b9c49a` 靠，深水往 `#22627e` 靠；岸边浅色带往 `#f4f1e6` 靠。
- 菲涅尔：从上往下看能看到水的颜色，越斜看越以倒影为主。
- 微波：两层缓慢流动的噪声让倒影轻轻晃动；多云、雨、雷暴时波动依次加大。
- 雨点涟漪：按 8 m 的格子随机冒出扩散的波纹，雨越大越多。
- 雨天深浅差变小、水面变粗糙（太阳高光变散）。
- 水位：鱼塘、湖压到岸边最低点以下 0.4 m，水库取岸边 15% 分位高度；地形在水面范围内挖低到水面下 1.5 m。

出处：`src/world/water.ts`、`src/core/region.ts`、`look/driver.ts`

## 8. 后期

顺序固定：**场景 → AO → 体积雾合成 → 全局调色 → 移轴 → 暗角 → 泛光**（`src/post/pipeline.ts`）。

| 环节 | 取值 |
|---|---|
| AO | 0.4 倍分辨率，半径 45；强度 0.85 × (1 − night) |
| 体积雾 | 两层（雾体、太阳照雾），0.35 倍分辨率计算再模糊；遮挡上限 0.95 |
| 全局调色 | 暗部偏 `shadow` 色、亮部偏 `high` 色（两种色先归一到亮度 1，只改色相）；强度 = 关键帧 grade × 0.55；饱和度 = 关键帧 sat |
| 移轴 | 画面中心偏下（0.55）向上下两侧渐变虚化；夜里减弱到 15% |
| 暗角 | 0.3 + 0.25 × night |
| 泛光 | bloom(强度 0.15, 半径 0.4, 阈值 0.8)，再乘 0.15 + 0.5 × night（闪电时 + 0.6） |
| 色调映射 | NeutralToneMapping，曝光 1.0；按 SDR（Rec.709）输出 |

## 9. 镜头与输出

- 镜头视角 32°（偏长焦，压缩透视，有沙盘模型感）。
- 默认机位：切块模式方位 200°、俯角 14°、距离 3600 m；全区模式方位 28°、俯角 33°、距离约全区半宽 × 2.1。
- 以**航拍、全景**为主，偶尔推近。重点地标的近景细节以后做到具体镜头时再定。
- 成片输出：**4K（3840×2160）60 帧，ProRes 422**（LT / HQ 可选）。字幕和花字在剪辑软件里做，沙盘只负责三维画面。
- 画面内的地名标签（阶段 5）：直接画在画面里，同时必须提供**一键关闭**。
- 预览可以用低画质保证流畅；渲染成片时用全画质。

## 10. 改动后的验收

改了任何影响画面的东西，至少检查：

1. **五个标准时刻**：清晨 6.3、正午 12.5、黄金时刻 17.4、蓝调 19.3、深夜 23。
2. **日出日落的氛围**：至少看"玫瑰"和"紫暮"（最容易把地面染得过浓）。
3. **天气**：晴、雨、雷暴（夜里看闪电）、雾、雪（等积雪积满）。
4. **两种范围**：虹桥切块 `http://localhost:5190/` 和全区 `http://localhost:5190/?full=1`。
5. **流畅度**：左上角显示帧率。全区预览不应明显低于改动前（目前在 M 系列 Mac、1792×1344 下约 50–60 帧）。
6. **控制台**没有报错（浏览器面板隐藏时启动会出现画布尺寸为 0 的报错，可以忽略）。
7. 对照第 11 节的"不要做"逐条看一遍。

## 12. 技术规范（写代码时必须遵守）

### 渲染

- **只用 WebGPU**：Three.js r186 的 `three/webgpu`（`WebGPURenderer`，不支持时自动降级 WebGL2）和 `three/tsl` 节点。
- **禁止**：`onBeforeCompile`、`ShaderMaterial`、`RawShaderMaterial`、手写 GLSL、`EffectComposer`。这些是旧 WebGL 版的写法，在 WebGPU 下不生效。
- 材质用 `MeshStandardNodeMaterial` 等节点材质，通过 `colorNode`、`emissiveNode`、`roughnessNode`、`positionNode` 等定制。
- 需要每帧变化的参数做成 `uniform()`，**只由 `look/driver.ts` 写入**；材质只读。
- 粒子用 `SpriteNodeMaterial` + 实例化（WebGPU 不支持大于 1 像素的点）。
- 一个 `reflector()` 只能给一组水面材质用（它渲染倒影时会把自己隐藏，第二个材质会读写冲突）。
- 体积雾用 `VolumeNodeMaterial`：它所在的图层里必须有灯光；它不响应 `DirectionalLight`，太阳照雾用 `SpotLight`；雾灯的阴影相机只拍普通物体层（`layers.set(0)`）。
- 树冠等实例颜色放在自定义实例属性里，不用 `instanceColor`（它在最后再乘一次，积雪会被染色）。

### 结构

```
src/style/     美术定义：一天的关键色、氛围、克制系数（artPalette.ts）；物体基础色板与沙盘尺度（palette.ts）
src/weather/   天气状态机 + 天气叠加到配色（不负责画）
src/look/      整帧共享的 uniform；光影驱动（唯一写 uniform 的地方）
src/geo/       数据与几何：地形查询、建筑体块、道路水系条带、虹桥模型、投影（与渲染无关）
src/world/     场景内容：把几何体配上节点材质
src/fx/        体积雾、雨雪、噪声
src/post/      后期链
src/camera/    镜头
src/ui/        面板
```

- **颜色和美术参数**放在 `style/`，或作为 uniform 由 `driver.ts` 写入；不要散落在各个文件里写死。
- 状态（时刻、播放、氛围、雾档位）只放在 `driver.state` 里；面板、以后的时间线都只改 state。
- 代码注释用中文，写"为什么"，说人话。

### 坐标与数据

- 单位米；**x 向东，z 向南**，y 向上；原点为光明区中心。
- 经纬度 → 沙盘坐标用 `geo/projection.ts` 的 `projectLngLat`（Web 墨卡托，原点 `[113.929007, 22.76207]`，比例 k ≈ 0.922，取自 `sandbox.json`）。
- 地表高度一律用 `terrain.heightAt`（已含高程夸张）；高程夸张用 `style/palette.ts` 的 `exaggerate`。
- 数据：`public/sandbox/sandbox.json`（约 3 万栋建筑、道路、水系、绿地、用地、轨道等）、`dem.bin`（高程）、`public/terrain/hongqiao-bridge.json`（虹桥）。`public/sandbox/landmarks/` 和 `models/` 是原版地标数据，留给阶段 5。

### 视频输出相关（阶段 1 起）

- 画面里的一切变化必须能**逐帧确定地复现**：用固定时间步长推进，随机数用固定种子。新写的每帧逻辑不要直接用 `Math.random()` 或真实时间。
- 4K 渲染时，任何效果都不能依赖窗口大小。
