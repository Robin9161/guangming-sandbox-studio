# 同步改动报告：光明沙盘 Studio → 沙盘深圳 gpu

日期：2026-10-21　｜　分支：`studio-sync`（基于 `main` 的 33e221d，**尚未提交**）

---

## 1. 发生了什么

10 月 20–21 日的「项目恢复」会话，把一整天的改进（做视频用的整套工具）做在了 `~/Documents/光明沙盘-Studio` 上。Studio 是从更早的 WebGPU MVP 拆出来的工程：只有光明一个区，没有讲解剧本、精细地标和全深圳地形。最新版是 `~/Downloads/沙盘深圳gpu`（11 个区、29 拍讲解剧本、风吹雾、积水模拟）。

两边代码结构完全不同（Studio 是纯 TypeScript 模块，最新版是 React + `scene/createSandbox.ts` 总装），所以不能直接拷文件，而是**按功能逐项移植**：能原样用的模块（时钟、时间线、离屏出帧、渲染服务等）直接复制后改接口；其余的接进最新版现有的代码。

## 2. 结论

- Studio 阶段 1–6 的全部功能、局域网分享、拖动修复、规范和方案文档，都已同步到最新版。
- 最新版原有的功能（11 个区、讲解剧本、主干道、地势、流域视图、风吹雾、积水）都保留，实测讲解剧本正常。
- 类型检查通过；开发模式、离线包（双击启动的 `dist/`）、其他区（南山）都能正常打开；渲染成片实测通过（见第 5 节）。
- 所有改动都在 `studio-sync` 分支上，还没有提交。

## 4. 和 Studio 行为不同的地方（使用时注意）

1. **地名标签默认画在画面里**（会进成片）。显示画面标签时，原来的网页标签（可以点击飞入的片区名）自动隐去；左侧「画面参数 → 画面里的地名标签 → 显示地名标签」关掉就回到原来的网页标签。讲解时始终用网页标签。
2. **载入预设后时间会停在预设的时刻**（Studio 里会继续走）。点 ▶ 继续。
3. 时间线的「时刻与天气」可以切换白天 / 夜晚 / 光影模式；预设也记画面模式。
4. 每个区有自己的时间线（光明叫「默认」，南山叫「nanshan·默认」……）。
5. 渲染任务只能在同一个区的页面里渲染。
