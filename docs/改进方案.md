# 沙盘深圳 · 做视频的改进方案

> 本方案最初在「光明沙盘 Studio」（`~/Documents/光明沙盘-Studio`，从早期 WebGPU MVP 拆出来的工程）里定稿并实施了阶段 0–6。
> 2026-10-21 发现 Studio 是旧版本，阶段 1–6 的全部改动已移植到本工程（沙盘深圳 gpu）。以后只在本工程里继续，Studio 不再开发。

## 目标

用光明区三维沙盘制作视频中的三维动画镜头：

- 画面足够美观（延续 ALTO 风格的配色系统、体积雾、水面、天气、夜景）
- 参数足够可调（所有美术参数都能实时调、能保存成预设、能做关键帧）
- 支持运镜和光效调整
- 最终输出 **4K（3840×2160）60 帧**，交给剪辑软件做后期和花字

网页原有的功能（11 个区、讲解剧本、主干道、地势、流域视图）全部保留。

## 已确定的决定

| 事项 | 决定 |
|---|---|
| 渲染技术 | WebGPU（Three.js WebGPU 渲染器，不支持的浏览器自动退回 WebGL2）；不做 WebGL 对比和降级测试 |
| 输出 | 4K60，**ProRes 422**（另可选 LT / HQ），由本地 ffmpeg 合成，不落地中间图片 |
| 后期 | 剪辑软件里做后期和花字；沙盘只负责三维画面 |
| 时间线编辑器 | 成熟的开源时间线编辑器（Theatre.js），与沙盘之间隔离接口，以后可替换 |
| 标签 | 直接画在画面里，并提供一键关闭 |
| 音画 | 时间线支持导入配音 / 音乐对节奏，也可以不导入、按设定时长渲染 |
| 镜头远近 | 以航拍、全景为主，偶尔推近；重点地标的近景细节待做镜头时再定 |
| 渲染电脑 | 与机器无关：任何装有新版 Chrome / Edge 和 Node.js 的 Mac 或 Windows 都能渲染（ffmpeg 随 `npm install` 装好） |
| 使用者 | 团队多人使用：界面要易用，配说明文档 |
| 预览 | 调镜头时可用「流畅」画质，渲染成片时自动切到精致画质 |

## 与 4K60 相关的注意事项

- **渲染速度**：本工程场景比 Studio 重得多（全深圳地形、25 个精细地标、全分辨率 GTAO）。实测（Apple M 系列、浏览器面板在后台，4K、8 次抗锯齿、180° 运动模糊）约 0.44 帧/秒，1 分钟成片约 2 小时以上；前台窗口会快一些。先用 1080p 试渲染确认画面，长片放到空闲时间渲染。
- **内存**：8GB 内存的机器上 4K 用多帧累积抗锯齿，不用放大超采样。
- **磁盘**：ProRes 422 在 4K60 下约 9GB/分钟（LT 约 6GB、HQ 约 13GB），长片建议输出到外接硬盘。
- **60 帧**：画面非常流畅，略带"游戏感"；需要电影感时可开可选的运动模糊（默认关闭）。
- **色彩**：按标准 SDR（Rec.709）输出，风格在沙盘里调好后烘焙进画面，剪辑软件里仍可再调色。
- **Theatre.js 许可**：核心库 Apache-2.0；编辑界面 AGPL-3.0，内部制作视频使用没有问题，但不能把改过的编辑器公开发布。

## 后续优化清单（2026-10-21 用户提出，按顺序做，每部分开始前先问；提交、推送 git 前也要先问）

**一、安全和验证（最优先）**
1. 提交代码；之后每完成一个阶段提交一次（推送另问）。
2. 长时间渲染压力测试：4K 全区渲染 30 秒到 1 分钟，观察 8GB 内存的 Mac 上内存是否持续增长、是否过热降频、能否完整出片。
3. 剪辑软件导入测试：用一段 5 秒的 ProRes 成片，检查颜色、亮度和预览是否一致（Rec.709 标记）。先问用的是 Premiere、达芬奇还是剪映。
4. 在 Windows 和同事电脑上测试渲染，以及局域网 HTTPS 分享下 WebGPU 是否可用。

**二、按分镜驱动**：要分镜表 / 镜头清单，再据此决定精细地标近景、阶段 7 叙事特效、各镜头的时刻和天气打磨优先级。

**三、制作流程**
1. 镜头单：把时间线、预设、镜头库、渲染任务合成一个"镜头"对象（编号、负责人、时间线、预设、画幅、渲染参数、状态：草稿 / 审片 / 定稿、版本号），并做一张总表。
2. 审片小样：渲染时同时输出 1080p MP4 小样，放到 NAS 或局域网页面上，方便手机审片。
3. 多机分段渲染：利用逐帧可复现的特性，把一条任务拆成帧段，由多台电脑分别渲染后自动拼接。
4. 画面回归检查：把规范第 10 节的人工验收自动化，标准时刻各渲染一张参考图，代码改动后自动比对、超过阈值时提示（`scripts/shots.mjs` 可以作为起点）。

**四、画面**
1. 夜景车流光带：主干道上缓慢流动的车头灯（白）和尾灯（红），注意规范 P6 的克制原则。
2. 在真实镜头里调好标签样式与密度、景深对焦手感、运动模糊默认快门角度。
3. 推近用的地标细节：等分镜确定后，只做用得到的地标。

**五、易用性**
1. 上手文档（启动、调参、出片，配截图或操作录屏）和 Theatre.js 中文操作说明。
2. 界面分「看效果」和「做镜头」两种模式，只显示当下需要的面板。
