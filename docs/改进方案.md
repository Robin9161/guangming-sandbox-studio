# 光明沙盘 Studio · 改进方案（定稿）

## 目标

制作光明区三维沙盘，用于视频中的三维动画镜头：

- 画面足够美观（延续 ALTO 风格的配色系统、体积雾、水面、天气、夜景）
- 参数足够可调（所有美术参数都能实时调、能保存成预设、能做关键帧）
- 支持运镜和光效调整
- 最终输出 **4K（3840×2160）60 帧**，交给剪辑软件做后期和花字

## 已确定的决定

| 事项 | 决定 |
|---|---|
| 渲染技术 | WebGPU（Three.js WebGPU 渲染器，不支持的浏览器自动退回 WebGL2）；原 WebGL 版不再继续开发 |
| 输出 | 4K60，**ProRes 422**（另可选 LT / HQ），由本地 ffmpeg 合成，不落地中间图片 |
| 后期 | 剪辑软件里做后期和花字；沙盘只负责三维画面 |
| 时间线编辑器 | 成熟的开源时间线编辑器（Theatre.js），与沙盘之间隔离接口，以后可替换 |
| 标签 | 直接画在画面里，并提供一键关闭 |
| 音画 | 时间线支持导入配音 / 音乐对节奏，也可以不导入、按设定时长渲染 |
| 镜头远近 | 以航拍、全景为主，偶尔推近；重点地标的近景细节待做镜头时再定 |
| 渲染电脑 | 与机器无关：任何装有新版 Chrome / Edge 和 ffmpeg 的 Mac 或 Windows 都能渲染 |
| 使用者 | 团队多人使用：界面要易用，配说明文档 |
| 预览 | 调镜头时用低画质预览保证流畅，渲染成片时自动切到全画质 |

## 路线图

| 阶段 | 内容 | 产出 |
|---|---|---|
| **0 工程底座** | 新建独立工程并纳入 git；以 WebGPU 版为基础；渲染层按功能拆分模块；移除旧 WebGL 代码；美术风格与设计规范；方案和说明文档 | ✅ 已完成 |
| **1 确定性渲染 + ProRes 输出** | 固定帧率逐帧推进；所有随机效果使用固定种子；渲染分辨率固定 3840×2160、与窗口无关；多帧累积抗锯齿（8GB 内存的机器也能跑 4K）；本地小工具接收每一帧交给 ffmpeg 合成 ProRes；渲染队列；渲染时防休眠；渲染时隐藏界面 | 第一次能直接出成片 |
| **2 参数系统** | 统一参数表（时间与天空、太阳与灯光、雾、水、夜景、天气、后期、图层显隐）；实时调参面板；预设保存 / 载入 / 对比；所有参数可做关键帧 | 边看边调、方案可复用 |
| **3 运镜 + 时间线** | 接入 Theatre.js；镜头装置（焦点、距离、方位、俯仰、焦距、景深焦点）；运镜模板（环绕、推拉、升降、平移、沿路径飞行，路径可取自道路 / 河流 / 地铁）；画幅与安全框（16:9 / 9:16 / 1:1 / 2.39:1）；镜头库；导入音频对节奏 | 能做运镜和镜头编排 |
| **4 光效** | 太阳方向可脱离时间单独控制；补光、轮廓光；重点区域体积光照明；夜景灯光系统（城市光点、路灯分布、片区活跃度窗户、地标彩灯）；导入 3D LUT | 电影式布光 |
| **5 内容补齐** | 标签画进画面（可一键关闭、样式可调）；精细地标；地铁、高铁、高速；闪电光束；少数重点地标的近景细节 | 内容完整 |
| **6 画质** | 景深（可做焦点转移）；近景阴影分级；远景简化；可选运动模糊 | 成片画质 |

## 与 4K60 相关的注意事项

- **渲染速度**：4K 每秒约能渲染几帧（取决于电脑和画质设置），1 分钟成片（3600 帧）约需十几分钟到半小时以上；建议用渲染队列在空闲时间渲染。MacBook Air 没有风扇，长时间渲染会降频。
- **内存**：8GB 内存的机器上 4K 不使用放大超采样，改用多帧累积抗锯齿。
- **磁盘**：ProRes 422 在 4K60 下约 9GB/分钟（LT 约 6GB、HQ 约 13GB），长片建议输出到外接硬盘。
- **60 帧**：画面非常流畅，略带"游戏感"；需要电影感时可开可选的运动模糊（默认关闭）。
- **色彩**：按标准 SDR（Rec.709）输出，风格在沙盘里调好后烘焙进画面，剪辑软件里仍可再调色。
- **Theatre.js 许可**：核心库 Apache-2.0；编辑界面 AGPL-3.0，内部制作视频使用没有问题，但不能把改过的编辑器公开发布。

## 已取消的规划

- 内容可信度检查（示意标注、数据缺口检查）
