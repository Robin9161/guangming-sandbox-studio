# 光明区微缩沙盘 · 独立包

这是从「深圳」项目里单独抽出来的 3D 沙盘页面，包含全部光影、夜景和天气效果，以及运行所需的地图数据。不依赖原项目，也不含任何 API 密钥。

想了解天气和光影是怎么做的，请看同目录下的 **《天气与光影系统说明.md》**。

---

## 一、只想打开看看（推荐）

`dist/` 文件夹里已经是构建好的网页，只需要用一个本地网页服务器打开它。

> ⚠️ 不能直接双击 `dist/index.html`：浏览器禁止网页从本地文件读取地图数据，页面会一直停在“搭建中…”。

**Mac**：双击 `启动沙盘（Mac）.command`，浏览器会自动打开 http://localhost:8790。
- 第一次运行如果提示“无法验证开发者”，在文件上右键 → 打开 → 再点“打开”。
- 需要电脑上有 Python 3（macOS 一般自带；没有的话系统会提示安装）。
- 关掉弹出的终端窗口，服务器就停止了。

**Windows**：双击 `启动沙盘（Windows）.bat`。
- 需要装有 Python 3（https://www.python.org ，安装时勾选 “Add python.exe to PATH”）或 Node.js（https://nodejs.org ）其中之一。

**手动启动**（任何系统）：在终端里进入 `dist` 文件夹，运行下面任意一条，然后打开 http://localhost:8790

```bash
python3 -m http.server 8790
```

```bash
npx serve -l 8790 .
```

## 二、想改代码（开发模式）

需要 Node.js 22 或以上。在本文件夹（不是 dist）里运行：

```bash
npm install
npm run dev
```

浏览器会打开 http://localhost:5173 ，改代码后页面自动刷新。改完想重新生成 `dist/`：

```bash
npm run build
```

## 三、怎么看效果

1. 右侧面板「✦ 光影」：打开连续的一天（约 4 分钟一天，夜里走 3 倍速）。可以拖时间滑块，或点“日出 / 黄金时刻 / 蓝调 / 深夜”等快捷时刻。
2. 「天气」一排按钮：自动、晴、多云、雨、雷暴、雾、雪。手动选择后 4 分钟内不会自动换。
3. 视角里的「天际线」：低机位朝北看光明中心，夜景和晨雾最好看的角度。
4. 推荐组合：天际线 + 日出（晨雾）、天际线 + 蓝调、微缩 + 深夜（城市灯海）、天际线 + 深夜 + 雷暴（闪电）。

## 四、文件夹结构

```
光明沙盘-独立包/
├── 启动沙盘（Mac）.command      双击打开（Mac）
├── 启动沙盘（Windows）.bat      双击打开（Windows）
├── README.md                    本文件
├── 天气与光影系统说明.md          天气、光影、夜景的原理和代码导读
├── dist/                        构建好的网页（直接用这个）
├── app/sandbox/                 沙盘源代码
│   ├── page.tsx                 页面和右侧面板
│   └── scene/                   3D 场景（天气、光影代码都在这里）
├── public/                      地图数据（地形、建筑、道路、地标、虹桥）
├── src/main.tsx                 独立包的入口
└── package.json / vite.config.ts  构建配置
```

## 五、说明

- 页面用到 WebGL，建议用较新的 Chrome、Edge 或 Safari。集成显卡也能跑；如果卡，可以点面板下方的“画质”切到“流畅”。
- 「南山」按钮切换到南山区的数据（数据较少，光明专属的地标、虹桥、讲解剧本不加载）。
