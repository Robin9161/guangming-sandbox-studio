# 沙盘深圳 · WebGPU

讲"光明为什么成了今天这样"的 3D 微缩沙盘网页（低多边形、马卡龙配色），可以按剧本自动讲解，也可以自由浏览深圳 11 个区；同时是**做视频三维动画镜头的工具**：参数面板、预设、Theatre.js 时间线运镜，直接渲染 4K60 ProRes 成片。

- **美术风格与设计规范**：[docs/美术风格与设计规范.md](docs/美术风格与设计规范.md)（接手的人和 AI 必读）
- 做视频的目标和路线图：[docs/改进方案.md](docs/改进方案.md)
- 天气和光影的原理：[天气与光影系统说明.md](天气与光影系统说明.md)
- 交接：[交接文档.md](交接文档.md)；AI 协作说明：[AGENTS.md](AGENTS.md)

## 一、只想打开看看

`dist/` 文件夹里是构建好的网页，只需要用一个本地网页服务器打开它。

> ⚠️ 不能直接双击 `dist/index.html`：浏览器禁止网页从本地文件读取地图数据，页面会一直停在"搭建中…"。

**Mac**：双击 `启动沙盘（Mac）.command`，浏览器会自动打开 http://localhost:8795 。
- 第一次运行如果提示"无法验证开发者"，在文件上右键 → 打开 → 再点"打开"。
- 需要电脑上有 Python 3（macOS 一般自带；没有的话系统会提示安装）。
- 关掉弹出的终端窗口，服务器就停止了。

**Windows**：双击 `启动沙盘（Windows）.bat`。需要装有 Python 3（安装时勾选 "Add python.exe to PATH"）或 Node.js 其中之一。

这种方式只能看和临时调参数：保存预设 / 时间线 / 镜头、渲染成片都需要下面的开发模式。

## 二、开发模式（改代码、做视频都用它）

需要 Node.js 22 以上，以及新版 Chrome 或 Edge（WebGPU）。在本文件夹（不是 dist）里运行：

```bash
npm install
```

```bash
npm run dev
```

浏览器会打开 http://localhost:5173 ，改代码后页面自动刷新。渲染服务、存档服务和 ffmpeg 随它一起启动（`npm install` 会自动装好 ffmpeg）。

- 切换区：左上角的区名按钮，或地址加 `?district=qianhai` 等；`?fps=1` 显示帧率。
- 改完想重新生成 `dist/`（双击打开用的就是它）：`npm run build`
- 类型检查：`npm run typecheck`
- 启动时终端刷一串「Assets in public directory cannot be imported」只是提醒，不影响使用。

**局域网分享（给同事看）**：

```bash
npm run share
```

在 5191 端口用 HTTPS 开一份打包好的版本（同事用 `https://这台电脑的IP:5191` 打开，第一次要在浏览器里信任自签名证书；证书放在 `.certs/`，不进版本库）。改完代码保存后会自动重新打包，同事刷新就能看到。从别的电脑打开是**只读**的：可以看、可以临时调参数，但不能保存预设 / 时间线 / 镜头，也不能渲染。

## 三、怎么看效果

1. 右侧面板「✦ 光影」：连续的一天（约 4 分钟一天，夜里走 3 倍速）。可以拖时间滑块，或点"日出 / 黄金时刻 / 蓝调 / 深夜"等快捷时刻。
2. 「天气」一排按钮：自动、晴、多云、雨、雷暴、雾、雪。手动选择后 4 分钟内不会自动换。
3. 视角里的「天际线」：低机位朝北看光明中心，夜景最好看的角度。
4. 「▶ 按剧本讲解光明」：29 拍的讲解剧本，带运镜、城市生长、路名浮现。
5. 推荐组合：天际线 + 日出、天际线 + 蓝调、微缩 + 深夜（城市灯海）、天际线 + 深夜 + 雷暴（闪电）。

## 四、做视频

### 界面

- **左侧「画面参数」**：所有美术参数，按组折叠（太阳与灯光、雾、夜景、天气、水、时间与天空、后期与镜头效果、画面里的地名标签）。组标题显示"改了几项"，改过的参数左边有橙色标记，每组最后有「本组恢复默认」。窗口窄时默认收起，点右上角 + 展开。
- **预设**（左侧面板最上面）：一套完整的画面风格（全部参数 + 画面模式、时刻、氛围、天气），存在工程 `presets/` 里，团队共享。选好点「载入」；「A/B」和载入前的画面来回切换；「另存为…」保存当前画面。自带 7 个：黄金时刻、清晨薄雾、正午晴、蓝调夜景、深夜雨、雪、雾天。
- **右侧面板最下面**两块可展开：「运镜与时间线」「渲染成片」。
- **画幅取景框**：画面铺满窗口，选定画幅（16:9 / 9:16 / 1:1 / 2.39:1）的取景范围用亮框标出、框外压暗；框里就是成片的构图。
- **地名标签**：默认直接画在画面里（会进成片），「画面参数 → 画面里的地名标签」可以关掉或调大小、分类显示；右侧「图层 → 标签」是总开关。讲解时改回网页标签。

### 运镜与时间线

1. **最简单的运镜**：选一个「运镜模板」（环绕 / 推拉 / 升降 / 平移 / 沿路径飞行：茅洲河、光明大道、光侨路、观光路、地铁 6 号线 / 6 号线支线 / 13 号线），填开始时间、时长、幅度，点「应用」，再点「▶ 播放时间线」看效果。不用打关键帧。
2. **打关键帧**：点「打开时间线编辑器」（Theatre.js）。在左上的大纲里选一个对象（镜头装置 / 运镜模板 / 时刻与天气 / 画面参数），在右侧属性名上**右键 →「Sequence」**，这个属性就能打关键帧了。把播放头拖到某个时间、改属性值，就会在那里记一个关键帧。
3. **用鼠标调镜头**：镜头跟随时间线时，在画面上一拖就会切回手动；转好视角后点「写入当前视角」——镜头交回时间线，属性打了关键帧时就在播放头位置记一个。
4. **镜头库**：把常用视角存起来（工程 `shots/` 里），以后一键调出。
5. **配音 / 音乐**：「导入音频」后，播放时间线时会同步播放，方便对节奏；渲染时可以选择把它写进成片。
6. **时间线文件**：存在工程 `timelines/` 里，改动后自动保存；每个区一条默认时间线（光明叫「默认」，其他区叫「nanshan·默认」等）；可以「另存为」再从列表里「打开」另一条。

三个「跟随时间线」开关决定哪些东西听时间线的（镜头 / 时刻与天气 / 画面参数），关掉就回到手动控制。「时刻与天气」里还能切换画面模式（白天 / 夜晚 / 光影）。

### 渲染成片（4K60 ProRes）

1. 用 `npm run dev` 打开页面。
2. 调好画面：画面模式、时刻、氛围、天气、镜头。不想让时间往前走，就点 ❚❚ 暂停。
3. 展开「渲染成片」，设置：
   - 内容：「当前画面」（按时长渲染，时间、天气按设定往前走）或「按时间线」（从 a 秒到 b 秒，镜头、时刻、参数都按时间线）
   - 尺寸：4K / 1080p 试渲染（画幅跟随「运镜与时间线」里选的画幅）
   - ProRes 规格（LT / 422 / HQ）、抗锯齿次数（默认 8）、运动模糊（快门角度，默认关）、是否带上导入的音频
4. 点「记下当前画面，加入队列」（可以记多条），再点「开始渲染队列」。队列为空时直接渲染当前画面。
5. 成片保存在工程的 `renders/` 里，旁边有同名 `.json`。用「导入任务」选这个文件，可以原样重渲。

注意：

- 渲染期间界面会隐藏，只显示进度和「取消」。**请让这个标签页留在前台**，不要在渲染时改代码（页面会热更新刷新，渲染会中断）。
- 速度：本工程场景较重，4K、8 次抗锯齿约每秒零点几帧，1 分钟成片要一两个小时。先用 1080p 试渲染确认画面。
- 磁盘：4K60 的 ProRes 422 约 9GB/分钟（LT 约 6GB、HQ 约 13GB）。
- 每条任务记下的是完整的起始状态（画面模式、时刻、氛围、天气状态机、随机数、模拟时间、镜头、图层、全部参数，按时间线渲染时还有整条时间线），加入队列后再改画面、改时间线，都不影响已经记下的任务。任务只能在同一个区的页面里渲染。
- 讲解剧本的状态（讲解运镜、城市生长、讲解动画、网页标签）不记进任务，渲染时讲解的运镜会停下。要出讲解里的镜头，先用时间线把运镜重做一遍（讲解的城市生长等效果目前还不能进成片，见改进方案）。
- 导入的 3D LUT 和音频只在本次打开页面期间有效；重渲旧任务时要重新导入同一个文件。
- 检查确定性（改了效果之后）：同一个任务渲两遍，逐帧比对：

```bash
node_modules/ffmpeg-static/ffmpeg -i renders/A.mov -i renders/B.mov -lavfi "[0][1]psnr" -f null -
```

## 五、文件夹结构

```
沙盘深圳gpu/
├── 启动沙盘（Mac）.command / （Windows）.bat   双击打开 dist/
├── app/sandbox/
│   ├── page.tsx                 页面和右侧面板（React）
│   ├── scene/                   3D 场景：createSandbox.ts 总装（数据、场景、后期、step / 渲染循环、讲解、做视频的接线）
│   │                            atmosphere.ts 光影 / artPalette.ts 一天的配色 / weather.ts 天气 / volumeFog.ts 体积雾 / waterGpu.ts 水面 ……
│   ├── landmarks/               各地标模型
│   └── studio/                  做视频用的工具
│       ├── clock.ts             模拟时间 simTime 和可复现的随机数 rng（成片逐帧复现的基础）
│       ├── params.ts            参数表：所有可调参数的唯一登记处（面板、预设、时间线都从这里生成）
│       ├── presets.ts           预设；LookControl（画面模式、时刻、天气的统一接口）
│       ├── timeline.ts          时间线（Theatre.js 只在这里出现）
│       ├── moves.ts paths.ts    镜头装置、运镜模板、沿河 / 路 / 地铁飞行的路径
│       ├── frameRenderer.ts     离屏出帧：固定尺寸、多帧累积抗锯齿、读回像素
│       ├── jobs.ts              渲染任务：起始状态快照、逐帧推进（抗锯齿 / 运动模糊）、送帧给本地服务
│       ├── frameLabels.ts       画在画面里的地名标签
│       ├── streetLights.ts      近处的路灯光点
│       ├── paramsPanel.ts timelinePanel.ts renderPanel.ts view.ts markup.ts studio.css   面板、画幅取景框
│       └── store.ts             本地存档（预设、镜头库、时间线）
├── tools/
│   ├── render-server.mjs        本地渲染服务（Vite 插件）：经 WebSocket 逐帧接收像素，交给 ffmpeg 合成 ProRes
│   ├── store-server.mjs         本地存档服务（Vite 插件）：预设、镜头库、时间线存成工程里的 JSON
│   ├── local-only.mjs           只接受本机的保存和渲染请求（局域网分享时同事是只读）
│   └── share.mjs                局域网分享（npm run share）
├── presets/ shots/ timelines/   预设、镜头库、时间线（跟着 git 给团队共享）
├── renders/                     成片输出（不进版本库）
├── public/sandbox/              全部数据：sandbox.json + dem.bin（光明）、districts/<区>/、shenzhen/、flood/、story-gpu/
├── scripts/                     批量截图、剧本逐拍检查
├── docs/                        规范、方案、WebGPU 迁移说明
└── src/main.tsx                 入口
```

调试：浏览器控制台里可以访问 `window.__sandbox`（场景、镜头、渲染器）和 `window.__studio`（参数、时间线、渲染接口）。

## 六、说明

- 页面用到 WebGPU，建议用较新的 Chrome、Edge 或 Safari。集成显卡也能跑；如果卡，可以点面板下方的"画质"切到"流畅"（渲染成片时自动用精致画质）。
- 「南山」等按钮切换到其他区的数据（光明专属的地标、虹桥、讲解剧本、主干道不加载）。
- 地图数据来自 OpenStreetMap 等，公开发布时页面必须注明「© OpenStreetMap contributors」（详见交接文档第 4 节）。
